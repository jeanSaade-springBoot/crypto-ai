Validated query rewrite without a new index
Current countDistinctSymbolsSince query:
SELECT COUNT(DISTINCT symbol) FROM trade_signal WHERE generated_at >= cutoff.
It uses the health generated-time index but symbol is not covered, requiring
base-table fetches. A separately executed result query returned 21 in 4,132 ms
including transport.

Candidate:
SELECT COUNT(DISTINCT recent.symbol)
FROM (SELECT symbol,interval_code,MAX(generated_at) latest_generated_at
      FROM trade_signal GROUP BY symbol,interval_code) recent
WHERE recent.latest_generated_at >= cutoff.
With the same fixed cutoff it also returned 21, in 210 ms including transport.
Its EXPLAIN ANALYZE root took 5.14 ms. MySQL performed a covering index skip scan
for grouping over 105 symbol/timeframe lanes instead of thousands of base rows.
This is one sampled equality check plus a semantics-preserving MAX equivalence,
not a broad production regression test or a deployed fix.

The same MAX-then-cutoff approach for signalStaleness used a covering grouping
skip scan, approximately 3.94 ms, and returned 52 lanes. Its original recent
sample returned 52 lanes in 28.6 ms. Exact key/timestamp equality was not compared;
verify it before implementation. The SQL equivalence preserves the inclusive
lower cutoff and does not introduce an upper cutoff.

Signal creation delay
For the latest 200 persisted one-minute signals, grouped by 16 symbols, average
candle-close-to-created_at delay per symbol was approximately 3.54-6.60 seconds;
the largest sampled delay was 14.425 seconds. This is candle input/queue/analysis/
row-creation delay, NOT isolated SQL time, exchange response latency, or commit
completion. It can include recovery. created_at does not prove transaction commit.
fix129_stage_timing had no samples in the previous hour. Stage-level evidence is
needed to attribute the delay between input, queue wait, external context reads,
analysis, locks, JDBC/pool waits, serialization, and commit. A database query
improvement should not be presented as a complete evaluation-latency fix.
