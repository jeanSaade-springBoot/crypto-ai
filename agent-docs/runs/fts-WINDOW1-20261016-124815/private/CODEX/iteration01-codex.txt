### DB_REQUEST

QueryId: DBQ-CODEX-I1-001  
Purpose: Confirm the actual current schema, columns, and foreign-key relationships before requesting the six frozen trade records and related execution/protection evidence.  
SQL:
```sql
SELECT
    c.table_name,
    c.ordinal_position,
    c.column_name,
    c.column_type,
    c.is_nullable,
    c.column_key,
    c.extra
FROM information_schema.columns c
WHERE c.table_schema = 'crypto_ai'
  AND c.table_name IN (
      'paper_position',
      'trade_signal',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'signal_processing_work'
  )
ORDER BY c.table_name, c.ordinal_position;

SELECT
    k.table_name,
    k.column_name,
    k.constraint_name,
    k.referenced_table_name,
    k.referenced_column_name
FROM information_schema.key_column_usage k
WHERE k.table_schema = 'crypto_ai'
  AND k.table_name IN (
      'paper_position',
      'trade_signal',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'signal_processing_work'
  )
  AND (
      k.referenced_table_name IS NOT NULL
      OR k.constraint_name = 'PRIMARY'
  )
ORDER BY k.table_name, k.constraint_name, k.ordinal_position;
```
