### DB_REQUEST
QueryId: DBQ-CODEX-I5-003  
Purpose: After DBQ-CODEX-I5-002 supplies entry signal times, retrieve only the pre-entry multi-timeframe context, opportunity state, and canonical price-event evidence needed to reconstruct each entry without look-ahead.  
SQL:
```sql
SELECT
    p.id AS paper_position_id,
    entry_signal.id AS entry_signal_id,
    context_signal.*
FROM crypto_ai.paper_position p
JOIN crypto_ai.trade_signal entry_signal ON entry_signal.id = p.signal_id
JOIN crypto_ai.trade_signal context_signal
  ON context_signal.symbol = entry_signal.symbol
 AND context_signal.generated_at <= entry_signal.generated_at
 AND (
        (context_signal.interval = '1m'
         AND context_signal.generated_at >= entry_signal.generated_at - INTERVAL 30 MINUTE)
     OR (context_signal.interval = '5m'
         AND context_signal.generated_at >= entry_signal.generated_at - INTERVAL 20 MINUTE)
     OR (context_signal.interval = '1h'
         AND context_signal.generated_at >= entry_signal.generated_at - INTERVAL 3 HOUR)
 )
WHERE p.id IN (104, 101, 96, 91, 82, 78)
ORDER BY p.id, context_signal.interval, context_signal.generated_at, context_signal.id;

SELECT
    p.id AS paper_position_id,
    eo.*
FROM crypto_ai.paper_position p
JOIN crypto_ai.trade_signal entry_signal ON entry_signal.id = p.signal_id
JOIN crypto_ai.execution_opportunity eo
  ON eo.symbol = entry_signal.symbol
 AND eo.started_at <= entry_signal.generated_at
WHERE p.id IN (104, 101, 96, 91, 82, 78)
ORDER BY p.id, eo.started_at, eo.id;

SELECT
    p.id AS paper_position_id,
    wt.id AS wallet_trade_id,
    mpe.*
FROM crypto_ai.paper_position p
JOIN crypto_ai.wallet_trade wt
  ON wt.signal_id = p.signal_id
 AND wt.side = 'BUY'
 AND wt.status = 'EXECUTED'
JOIN crypto_ai.market_price_event mpe
  ON mpe.symbol = wt.symbol
 AND mpe.observed_at BETWEEN wt.execution_price_observed_at - INTERVAL 1 SECOND
                         AND wt.execution_price_observed_at + INTERVAL 1 SECOND
WHERE p.id IN (104, 101, 96, 91, 82, 78)
ORDER BY p.id, wt.executed_at, mpe.observed_at, mpe.id;
```
### END_DB_REQUEST
