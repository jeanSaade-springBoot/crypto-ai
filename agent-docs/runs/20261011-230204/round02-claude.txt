## OBJECTIONS

1. **Codex's Round-1 list misses the four code-level blockers** (F-01, F-02, F-03, F-05). [AGENT INFERENCE]
   - Codex's blockers are mostly governance and evidence gaps. Mine show that the spec's own claims are wrong against the code.
   - If the governance gaps alone were fixed, a re-freeze would still encode the wrong signal-path order and a false D14 equivalence.
2. **The label contradiction (Codex, and my F-07) is agreed.** [AGENT INFERENCE] I add one point: refusal granularity (whole run versus per span, §1 against D25 and §3.3) is part of the same defect.
3. **Statistics.** [AGENT INFERENCE] Judging 99% on a lower confidence bound needs about 300 or more comparable units per metric, even with zero mismatches (rule of three). §7.1 asks for per-exit-class reporting. If acceptance applies per class, rare classes (hard floor, near-TP, POSITION_STOP_LOSS) will never be evaluable. If it applies only overall, the §7.2 zero-critical-mismatch gate carries all the safety weight. The spec must choose before E06 is run, or the threshold-tuning risk Appendix C-2 warns about returns.
4. **Selective exclusion.** [AGENT INFERENCE] I agree with Codex's point. Both sets of non-comparable classes enlarge the excluded set without a cap: "wallet-driven", "configuration not recoverable" (E10) and "availability not reconstructable" (§3.6). Coverage floor (a) is the only guard and it has no value. Freeze needs at least the method that will set it.
