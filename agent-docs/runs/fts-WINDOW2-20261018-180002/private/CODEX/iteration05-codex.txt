### DB_REQUEST

QueryId: DBQ-CODEX-I5-001  
Purpose: Read deployed schema before selecting entry-quality columns, retrieve the six authoritative positions, and independently re-prove frozen selection. This is bounded, read-only, and confined to `crypto_ai`.

SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'trade_signal',
      'signal_processing_work',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'execution_opportunity',
      'wallet_settings',
      'candle',
      'technical_indicator'
  )
ORDER BY table_name, ordinal_position
LIMIT 1000;

SELECT p.*
FROM crypto_ai.paper_position p
WHERE p.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(p.id, 182, 172, 162, 158, 143, 137)
LIMIT 6;

SELECT
    id,
    status,
    closed_at,
    realized_pnl
FROM crypto_ai.paper_position
WHERE status = 'CLOSED'
  AND closed_at IS NOT NULL
  AND realized_pnl < 0
ORDER BY closed_at DESC
LIMIT 6;
```
