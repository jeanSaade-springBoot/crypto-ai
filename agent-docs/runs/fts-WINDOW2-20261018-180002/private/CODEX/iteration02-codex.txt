### DB_REQUEST

QueryId: DBQ-CODEX-I2-001  
Purpose: Obtain the deployed schema and the six authoritative position rows while independently re-proving the frozen failed-trade selection. All statements are bounded, read-only, and confined to `crypto_ai`.

SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'trade_signal',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'production_exit_audit',
      'position_management_event',
      'signal_processing_work',
      'candle',
      'technical_indicator'
  )
ORDER BY table_name, ordinal_position
LIMIT 1000;

SELECT p.*
FROM paper_position p
WHERE p.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(p.id, 182, 172, 162, 158, 143, 137)
LIMIT 6;

SELECT
    id,
    status,
    closed_at,
    realized_pnl
FROM paper_position
WHERE status = 'CLOSED'
  AND closed_at IS NOT NULL
  AND realized_pnl < 0
ORDER BY closed_at DESC
LIMIT 6;
```
