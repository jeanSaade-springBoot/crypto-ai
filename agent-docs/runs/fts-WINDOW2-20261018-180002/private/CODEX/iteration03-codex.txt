### DB_REQUEST

QueryId: DBQ-CODEX-I3-001  
Purpose: Establish deployed schema for timing/protection evidence and obtain the six authoritative position rows needed to form exact, bounded per-trade timing queries. Read-only; `crypto_ai` only.

SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'fix129_stage_timing',
      'production_exit_audit',
      'position_management_event',
      'signal_processing_work',
      'trade_signal'
  )
ORDER BY table_name, ordinal_position
LIMIT 1000;

SELECT p.*
FROM crypto_ai.paper_position p
WHERE p.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(p.id, 182, 172, 162, 158, 143, 137)
LIMIT 6;
```
