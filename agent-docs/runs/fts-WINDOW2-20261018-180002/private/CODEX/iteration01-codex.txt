### DB_REQUEST

QueryId: DBQ-CODEX-I1-001  
Purpose: Read the deployed `crypto_ai` schema before selecting trade-specific evidence. This identifies the actual columns available for the six frozen `paper_position` reconstructions and related signal, execution, protection, audit, work, candle, and indicator evidence.

SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'trade_signal',
      'wallet_trade',
      'wallet_managed_position',
      'market_price_event',
      'production_exit_audit',
      'position_management_event',
      'signal_processing_work',
      'candle',
      'technical_indicator'
  )
ORDER BY table_name, ordinal_position
LIMIT 1000;
```
