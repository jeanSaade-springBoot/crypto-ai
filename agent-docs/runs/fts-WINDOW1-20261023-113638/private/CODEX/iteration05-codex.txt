- **[PROJECT EVIDENCE]** Current code separates signal quality from entry quality. A bullish signal is not sufficient: at execution the system obtains a fresh price, recomputes entry quality against that price, and can cancel an otherwise approved BUY if price is already at/below the stop, at/above target, or classified as a chase.

- **[PROJECT EVIDENCE]** Current entry-quality scoring uses only contemporaneous/persisted pre-entry evidence: rolling 30-minute signal prices; a fresh opportunity anchor/best price when applicable; execution-price expansion; ATR extension; risk/reward at execution price; opportunity age; recent rejection-zone evidence; high-volatility regime; and `STOP_EXPOSED` liquidity state. Score under 50 is `CHASE_ENTRY` and blocks an initial entry; higher scores cap initial allocation by tier.

- **[PROJECT EVIDENCE]** Current execution validation additionally requires a 1m execution signal plus fresh 5m (20-minute) and 1h (3-hour) context, with profile-specific authority. This describes the checked-in source, not the historical release/configuration governing any frozen trade.
