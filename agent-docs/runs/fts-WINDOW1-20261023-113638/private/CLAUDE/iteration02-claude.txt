**F-I2-06: Trade 143 hit its original target, then the profit was given back. An 8-second gap in price data let the exit happen below the hard floor.** [PROJECT EVIDENCE + AGENT INFERENCE]
- **Levels.**
  - Signal target: 4.064697, i.e. 3×ATR from 4.032.
  - Paper target at close: 4.104317. That is exactly two +50% target extensions (4.033 → 4.0805 → 4.1043), following `TRADING_RULES.md:99`.
  - Highest price: 4.101.
  - Profit lock switched on at 22:40:23.057 UTC (01:40:23.057 KSA, 12 Oct), 18 seconds after entry.
- **The gap.** The last high tick was 22:43:27.038 UTC at 4.100. The next tick was 22:43:35.021 UTC at 4.027 (01:43:35.021 KSA), −1.78%. No event of any delivery status was stored in between (I1-011 window; I1-009 shows only `APPLIED` rows).
- **The exit.** The exit fired on the first tick below the hard floor 4.0350165 (= 4.033 × 1.0005). The rule fired as written; the tick gap is why the fill was 4.027 instead of near 4.035.
- **Design issue.** [AGENT INFERENCE] Price passed the original target, the system extended the target instead of taking profit, and the trade ended at a loss. This is a design-outcome issue, not a code defect. It relates to the FIX-155 near-TP study.
- **Re-entry.** A previous EGLD position (wallet_trade 357, `POSITION:171:PROFIT_LOCK_EXIT`) exited at 3.996 at 22:39:41.052 UTC. Trade 143 then bought 22 seconds later at 4.033, 0.93% higher.

  - [AGENT INFERENCE] Using only information available at entry, this was a chase. The outcome went in its favour anyway.

**F-I2-09: Timing anomalies that are not yet explained.** [PROJECT EVIDENCE + AGENT INFERENCE]
- **Paper record lags the wallet record by 1.2–3.2 s.**
  - At entry, `paper_position.opened_at` is consistently 1.7–2.2 s after the wallet BUY. For 182: BUY 09:57:04.232, paper opened 09:57:06.476 UTC.
  - For live-price exits, `closed_at` is 1.2–3.2 s after the wallet SELL. For 137: SELL 21:00:08.935, paper closed 21:00:12.122 UTC.
  - The signal-path exit (162) has no lag.
  - AGENTS.md requires paper effects to commit atomically, so this needs a code check: different clocks within one transaction, or separate transactions.
- **Signal timestamps.** `trade_signal.created_at` is consistently 1.3–2.3 s after `generated_at`.
- **Host clock vs Binance.** `market_price_event.created_at` is up to about 150 ms *earlier* than `observed_at` (Binance event time). Example: 162, observed 04:01:46.613, created 04:01:46.463. This points to a small clock offset between the host and Binance.
- **Work row with no position link.** For 158, `signal_processing_work.paper_position_id` is NULL, and the work row completed at 02:35:02.882, before the paper position opened at 02:35:04.811. The trade was executed through the 5m wake-up path instead.
- **HOLD recommendation, but closed anyway.** In five of six exit audits the position analysis recommended `HOLD`, but the position was still closed by the live exit rule. That may be the intended design (`TRADING_RULES.md:116` says position analysis is advisory) but should be confirmed.

### DB_REQUEST
QueryId: DBQ-CLAUDE-I2-006
Purpose: Get system-wide outcomes by exit type, and by stop basis (0.5% floor vs 2×ATR) and R:R bucket, to test F-I2-03 beyond the six-trade sample (U-11). Uses the entry signal's own stop/target because paper stops can move up.
SQL:
SELECT status, close_reason, COUNT(*) n, SUM(realized_pnl>0) wins, ROUND(SUM(realized_pnl),6) pnl,
       ROUND(AVG((exit_price-entry_price)/entry_price*100),4) avg_move_pct
FROM paper_position WHERE closed_at IS NOT NULL GROUP BY status, close_reason ORDER BY n DESC;
SELECT CASE WHEN ts.risk_reward_ratio < 1 THEN 'RR<1' ELSE 'RR>=1' END rr_bucket,
       CASE WHEN ABS((ts.latest_price-ts.stop_loss)/ts.latest_price*100 - 0.5) < 0.001 THEN 'FLOOR_0.50' ELSE 'ATR_BASED' END stop_basis,
       COUNT(*) n, SUM(pp.realized_pnl>0) wins, ROUND(SUM(pp.realized_pnl),6) pnl,
       ROUND(AVG(ts.atr_percent),4) avg_atr_pct,
       ROUND(AVG((ts.take_profit-ts.latest_price)/ts.latest_price*100),4) avg_tp_pct,
       SUM(pp.status='STOPPED') stopped
FROM paper_position pp JOIN trade_signal ts ON ts.id = pp.signal_id
WHERE pp.closed_at IS NOT NULL GROUP BY rr_bucket, stop_basis;
