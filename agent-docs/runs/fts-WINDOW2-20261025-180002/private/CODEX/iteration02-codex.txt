### DB_REQUEST

QueryId: DBQ-CODEX-I2-001  
Purpose: Read the actual schema before selecting linked forensic columns and joins for the six frozen positions.  
SQL:
```sql
SELECT
    table_name,
    column_name,
    column_type,
    is_nullable,
    column_key,
    extra
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'trade_signal',
      'wallet_managed_position',
      'wallet_trade',
      'production_exit_audit',
      'position_analysis',
      'position_management_event',
      'signal_processing_work',
      'market_price_event',
      'candle'
  )
ORDER BY table_name, ordinal_position;
```
### END_DB_REQUEST
