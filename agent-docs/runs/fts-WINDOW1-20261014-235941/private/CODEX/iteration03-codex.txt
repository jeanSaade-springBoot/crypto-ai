### DB_REQUEST
QueryId: DBQ-CODEX-I3-001  
Purpose: Confirm authoritative `paper_position` identities and test the candidate wallet-position/log correlation before attributing any timing or protection event to a frozen trade.  
SQL:
```sql
SELECT pp.*
FROM crypto_ai.paper_position AS pp
WHERE pp.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(pp.id, 182, 172, 162, 158, 143, 137);

SELECT wmp.*
FROM crypto_ai.wallet_managed_position AS wmp
WHERE wmp.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(wmp.id, 182, 172, 162, 158, 143, 137);

SELECT ts.*
FROM crypto_ai.trade_signal AS ts
WHERE ts.id IN (
    SELECT pp.signal_id
    FROM crypto_ai.paper_position AS pp
    WHERE pp.id IN (182, 172, 162, 158, 143, 137)
      AND pp.signal_id IS NOT NULL
    UNION
    SELECT pp.exit_signal_id
    FROM crypto_ai.paper_position AS pp
    WHERE pp.id IN (182, 172, 162, 158, 143, 137)
      AND pp.exit_signal_id IS NOT NULL
)
ORDER BY ts.id;
```

### DB_REQUEST
QueryId: DBQ-CODEX-I3-002  
Purpose: Retrieve bounded accepted and non-accepted price-event evidence around each authoritative close, to establish the trigger observation and possible protection timing gap.  
SQL:
```sql
SELECT
    pp.id AS paper_position_id,
    pp.symbol,
    pp.closed_at AS position_closed_at_utc,
    mpe.id AS market_price_event_id,
    mpe.observed_at AS observed_at_utc,
    mpe.created_at AS event_created_at_utc,
    mpe.price,
    mpe.source,
    mpe.delivery_status,
    mpe.outcome_reason
FROM crypto_ai.paper_position AS pp
LEFT JOIN crypto_ai.market_price_event AS mpe
  ON mpe.symbol = pp.symbol
 AND mpe.observed_at >= DATE_SUB(pp.closed_at, INTERVAL 2 MINUTE)
 AND mpe.observed_at <= DATE_ADD(pp.closed_at, INTERVAL 30 SECOND)
WHERE pp.id IN (182, 172, 162, 158, 143, 137)
ORDER BY pp.id, mpe.observed_at, mpe.id;
```
### END_DB_REQUEST
