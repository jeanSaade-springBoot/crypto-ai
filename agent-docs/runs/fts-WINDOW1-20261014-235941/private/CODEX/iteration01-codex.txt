### DB_REQUEST
QueryId: DBQ-CODEX-I1-001  
Purpose: Establish the actual `crypto_ai` schemas and foreign-key lineage before requesting trade-specific columns or joining records.  
SQL:
```sql
SELECT
    c.table_name,
    c.ordinal_position,
    c.column_name,
    c.column_type,
    c.is_nullable,
    c.column_key,
    c.extra
FROM information_schema.columns c
WHERE c.table_schema = 'crypto_ai'
  AND c.table_name IN (
      'paper_position',
      'trade_signal',
      'signal_processing_work',
      'wallet_trade',
      'wallet_managed_position',
      'position_analysis',
      'market_price_event',
      'candle',
      'technical_indicator'
  )
ORDER BY c.table_name, c.ordinal_position;

SELECT
    k.table_name,
    k.constraint_name,
    k.column_name,
    k.referenced_table_name,
    k.referenced_column_name
FROM information_schema.key_column_usage k
WHERE k.table_schema = 'crypto_ai'
  AND k.table_name IN (
      'paper_position',
      'trade_signal',
      'signal_processing_work',
      'wallet_trade',
      'wallet_managed_position',
      'position_analysis',
      'market_price_event'
  )
  AND k.referenced_table_name IS NOT NULL
ORDER BY k.table_name, k.constraint_name, k.ordinal_position;
```
