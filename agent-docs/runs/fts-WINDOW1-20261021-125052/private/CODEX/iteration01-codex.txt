### DB_REQUEST

QueryId: DBQ-CODEX-I1-001  
Purpose: Read the actual `crypto_ai` schemas for the authoritative position entity and candidate evidence tables before selecting columns or constructing joins for the six frozen trades.  
SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'wallet_trade',
      'wallet_managed_position',
      'trade_signal',
      'signal_processing_work',
      'market_price_event',
      'position_management_event',
      'production_exit_audit',
      'position_analysis'
  )
ORDER BY table_name, ordinal_position;
```
