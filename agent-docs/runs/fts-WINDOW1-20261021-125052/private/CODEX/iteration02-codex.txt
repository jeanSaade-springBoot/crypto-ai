### DB_REQUEST

QueryId: DBQ-CODEX-I2-001  
Purpose: Obtain the authoritative entity’s actual schema and its six bounded lifecycle records before selecting specific fields or constructing joins.  
SQL:
```sql
SELECT
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key,
    column_default,
    extra
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name = 'paper_position'
ORDER BY ordinal_position;

SELECT p.*
FROM crypto_ai.paper_position AS p
WHERE p.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(p.id, 182, 172, 162, 158, 143, 137);
```

### DB_REQUEST

QueryId: DBQ-CODEX-I2-002  
Purpose: Confirm the schemas of documented candidate evidence entities, without assuming their existence or join columns.  
SQL:
```sql
SELECT
    c.table_name,
    c.ordinal_position,
    c.column_name,
    c.column_type,
    c.is_nullable,
    c.column_key
FROM information_schema.columns AS c
WHERE c.table_schema = 'crypto_ai'
  AND c.table_name IN (
      'wallet_trade',
      'wallet_managed_position',
      'trade_signal',
      'signal_processing_work',
      'market_price_event',
      'position_management_event',
      'production_exit_audit',
      'position_analysis',
      'candle',
      'technical_indicator'
  )
ORDER BY c.table_name, c.ordinal_position;
```
### END_DB_REQUEST
