QueryId: DBQ-CODEX-I5-002  
Purpose: After DBQ-CODEX-I5-001 confirms the mappings, retrieve each frozen position’s actual entry signal and wallet BUY execution evidence, including decision-price versus observed execution-price timing.  
SQL:
```sql
SELECT
    p.id AS paper_position_id,
    p.opened_at AS paper_opened_at_utc,
    p.entry_price AS paper_entry_price,
    p.signal_id AS entry_signal_id,
    s.*,
    wt.id AS wallet_buy_trade_id,
    wt.execution_key,
    wt.price_usdt AS wallet_execution_price,
    wt.decision_price_usdt,
    wt.execution_price_observed_at,
    wt.quantity AS wallet_buy_quantity,
    wt.gross_amount_usdt,
    wt.fee_usdt,
    wt.execution_reason,
    wt.execution_message,
    wt.executed_at AS wallet_executed_at_utc
FROM crypto_ai.paper_position p
LEFT JOIN crypto_ai.trade_signal s
  ON s.id = p.signal_id
LEFT JOIN crypto_ai.wallet_trade wt
  ON wt.signal_id = p.signal_id
 AND wt.side = 'BUY'
 AND wt.status = 'EXECUTED'
WHERE p.id IN (182, 172, 162, 158, 143, 137)
ORDER BY p.id, wt.executed_at, wt.id;
```

### DB_REQUEST

QueryId: DBQ-CODEX-I5-003  
Purpose: After schema confirmation, obtain strictly as-of entry context needed to assess freshness, 5m/1h authority, and the 30-minute Entry Quality reference; no future signal may be used.  
SQL:
```sql
WITH entry_signal AS (
    SELECT
        p.id AS paper_position_id,
        p.signal_id AS entry_signal_id,
        s.symbol,
        s.generated_at AS entry_signal_generated_at_utc
    FROM crypto_ai.paper_position p
    JOIN crypto_ai.trade_signal s
      ON s.id = p.signal_id
    WHERE p.id IN (182, 172, 162, 158, 143, 137)
),
context_signals AS (
    SELECT
        e.paper_position_id,
        e.entry_signal_id,
        e.entry_signal_generated_at_utc,
        c.*
    FROM entry_signal e
    JOIN crypto_ai.trade_signal c
      ON c.symbol = e.symbol
     AND c.interval IN ('1m', '5m', '1h')
     AND c.generated_at <= e.entry_signal_generated_at_utc
     AND c.generated_at >= e.entry_signal_generated_at_utc - INTERVAL 3 HOUR
)
SELECT *
FROM context_signals
ORDER BY paper_position_id, interval, generated_at;
```
