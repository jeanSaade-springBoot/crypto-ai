Purpose: Establish the actual `crypto_ai` schema and identify the available forensic entities before selecting columns.  
SQL:
```sql
SELECT
    table_name,
    ordinal_position,
    column_name,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'wallet_trade',
      'managed_position',
      'trade_signal',
      'signal_processing_work',
      'market_price_event',
      'candle',
      'technical_indicator'
```

### DB_REQUEST

QueryId: DBQ-CODEX-I2-003  
Purpose: Determine durable database links into and out of the authoritative position entity, without assuming column names.  
SQL:
```sql
SELECT
    kcu.table_name,
    kcu.constraint_name,
    kcu.column_name,
    kcu.referenced_table_name,
    kcu.referenced_column_name
FROM information_schema.key_column_usage kcu
WHERE kcu.table_schema = 'crypto_ai'
  AND (
      kcu.table_name = 'paper_position'
      OR kcu.referenced_table_name = 'paper_position'
  )
ORDER BY
    kcu.table_name,
    kcu.constraint_name,
    kcu.ordinal_position;
```

### END_DB_REQUEST
