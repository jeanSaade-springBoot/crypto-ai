## FINDINGS

| ID | Finding | Label |
|---|---|---|
| **F-I2-01** | **The reward:risk is below 1 on 5 of the 6 entries.** The ratios are 0.48 (182), 0.74 (172), 0.44 (162), 0.33 (158) and 0.64 (137); 143 is 1.50. In each of the five, the stop sits 0.49–0.50% below entry, but the target is only 0.17–0.37% above it. The cause is in `AtrRiskService.java:34-45`. The stop distance is `max(2×ATR, 0.5% of price)`, using `minimum-stop-percent: 0.50` (`application.yml:143`). The target distance is `3×ATR` and has **no matching minimum**. So whenever ATR is below about 0.167% of price, the target ends up closer than the stop. These entries had ATR of 0.05–0.12%. | PROJECT EVIDENCE |
| F-I2-02 | **No global minimum reward:risk gate was found.** Searching `src/main` for a minimum-R:R property or comparison found nothing. Only some entry routes check R:R: `ExecutionIntelligenceService.java:1455` (transition route, rejects R:R ≤ 0) and `:1539` (`BREAKOUT_RETRACEMENT_MIN_RR`). I have not yet confirmed whether `assessEntryQuality` penalises a low R:R. | PROJECT EVIDENCE (search); AGENT INFERENCE (not exhaustive) |
| **F-I2-03** | **The targets are about the size of the trading fees.** Recorded P&L is gross, because `fee_usdt = 0` (DBQ-I1-005). At Binance's default spot fee of 0.1% per side, a round trip costs about 0.2%. That is larger than the target distance on 158 (0.17%) and 162 (0.22%), and about equal to it on 182 (0.24%). On roughly 260 USDT of buy-plus-sell volume, the estimated fees of about 0.26 USDT would roughly double the gross loss. | PROJECT EVIDENCE (distances, fee=0); EXTERNAL RESEARCH (fee rate); AGENT INFERENCE (estimate) |

### DB_REQUEST
QueryId: DBQ-CLAUDE-I2-004
Purpose: Price path in the 60 minutes after each exit, to judge whether exiting was right (U-I2-03).
SQL:
SELECT p.id AS position_id, p.symbol, p.exit_price, p.stop_loss, p.take_profit,
       COUNT(*) AS events, MAX(e.price) AS max_after, MIN(e.price) AS min_after,
       (MAX(e.price) - p.exit_price) / p.exit_price * 100 AS max_rebound_pct,
       (MIN(e.price) - p.exit_price) / p.exit_price * 100 AS max_further_drop_pct,
       MIN(CASE WHEN e.price >= p.take_profit THEN e.observed_at END) AS first_tp_touch,
       MIN(CASE WHEN e.price <= p.stop_loss THEN e.observed_at END) AS first_sl_touch
FROM paper_position p
JOIN market_price_event e ON e.symbol = p.symbol
 AND e.observed_at > p.closed_at AND e.observed_at <= p.closed_at + INTERVAL 60 MINUTE
WHERE p.id IN (182,172,162,158,143,137)
GROUP BY p.id, p.symbol, p.exit_price, p.stop_loss, p.take_profit
ORDER BY p.id DESC;
### END_DB_REQUEST

### DB_REQUEST
QueryId: DBQ-CLAUDE-I2-005
Purpose: The latest 5m and 1h signals at entry and at exit, for each position (U-I2-02, entry context).
SQL:
SELECT x.position_id, x.moment, x.iv, s.id, s.candle_open_time, s.generated_at, s.decision,
       s.original_decision, s.total_score, s.trend_score, s.momentum_score, s.confidence_score,
       s.final_entry_allowed, s.atr_immediate_entry_allowed, s.atr_recommended_position_percent,
       s.data_quality_valid, s.market_regime
FROM (
  SELECT p.id AS position_id, 'ENTRY' AS moment, iv.iv,
         (SELECT t.id FROM trade_signal t WHERE t.symbol = p.symbol AND t.interval_code = iv.iv
            AND t.generated_at <= es.generated_at ORDER BY t.generated_at DESC LIMIT 1) AS sid
  FROM paper_position p JOIN trade_signal es ON es.id = p.signal_id
  CROSS JOIN (SELECT '5m' AS iv UNION ALL SELECT '1h') iv
  WHERE p.id IN (182,172,162,158,143,137)
  UNION ALL
  SELECT p.id, 'EXIT', iv.iv,
         (SELECT t.id FROM trade_signal t WHERE t.symbol = p.symbol AND t.interval_code = iv.iv
            AND t.generated_at <= p.closed_at ORDER BY t.generated_at DESC LIMIT 1)
  FROM paper_position p
  CROSS JOIN (SELECT '5m' AS iv UNION ALL SELECT '1h') iv
  WHERE p.id IN (182,172,162,158,143,137)
) x JOIN trade_signal s ON s.id = x.sid
ORDER BY x.position_id DESC, x.moment, x.iv;
### END_DB_REQUEST

### DB_REQUEST
QueryId: DBQ-CLAUDE-I2-008
Purpose: Test whether F-I2-01 is systemic: losses and P&L by reward:risk band and by close reason, across all Production positions (U-I2-05, F-I2-14).
SQL:
SELECT CASE WHEN s.risk_reward_ratio < 0.5 THEN 'a_<0.5'
            WHEN s.risk_reward_ratio < 1.0 THEN 'b_0.5-1.0'
            WHEN s.risk_reward_ratio < 1.5 THEN 'c_1.0-1.5'
            ELSE 'd_>=1.5' END AS rr_bucket,
       p.status, COUNT(*) AS n, SUM(p.realized_pnl < 0) AS losses,
       SUM(p.realized_pnl >= 0) AS non_losses, SUM(p.realized_pnl) AS sum_pnl,
       AVG((p.exit_price - p.entry_price) / p.entry_price * 100) AS avg_move_pct
FROM paper_position p JOIN trade_signal s ON s.id = p.signal_id
WHERE p.status IN ('CLOSED','STOPPED') AND p.closed_at IS NOT NULL
GROUP BY rr_bucket, p.status
ORDER BY rr_bucket, p.status;

SELECT status, close_reason, COUNT(*) AS n, SUM(realized_pnl < 0) AS losses,
       SUM(realized_pnl) AS sum_pnl, MIN(closed_at) AS first_close, MAX(closed_at) AS last_close
FROM paper_position
WHERE closed_at IS NOT NULL
GROUP BY status, close_reason
ORDER BY n DESC;
