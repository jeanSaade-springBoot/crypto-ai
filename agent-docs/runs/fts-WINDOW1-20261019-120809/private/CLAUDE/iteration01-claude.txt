**F-I1-03 — AGENT INFERENCE.** The join path for each trade is:

| From | To | Join |
|---|---|---|
| paper_position.signal_id | trade_signal | entry signal |
| paper_position.signal_id | wallet_managed_position.entry_signal_id | managed position |
| wallet_managed_position.id | position_management_event | position events |
| paper_position.id | production_exit_audit | exit audit |
| paper_position.signal_id / exit_signal_id, symbol + time window | wallet_trade | buys and sells |

The schema has no direct foreign key from `wallet_trade` to `paper_position`. That is why exit trades are matched by symbol and time window. This link is unverified.
