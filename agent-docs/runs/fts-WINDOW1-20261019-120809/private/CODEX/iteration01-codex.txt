### DB_REQUEST

QueryId: DBQ-CODEX-I1-001  
Purpose: Read the actual `crypto_ai` schema for the bounded entities needed to reconstruct only the six frozen `paper_position` trades before selecting any data columns.

SQL:
```sql
SELECT
    table_name,
    column_name,
    ordinal_position,
    column_type,
    is_nullable,
    column_key
FROM information_schema.columns
WHERE table_schema = 'crypto_ai'
  AND table_name IN (
      'paper_position',
      'wallet_trade',
      'wallet_managed_position',
      'trade_signal',
      'signal_processing_work',
      'market_price_event',
      'production_exit_audit',
      'position_management_event',
      'candle',
      'technical_indicator'
  )
ORDER BY table_name, ordinal_position;
```
