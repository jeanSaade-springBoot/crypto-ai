### DB_REQUEST

QueryId: DBQ-CODEX-I1-003  
Purpose: Retrieve the directly linked entry/exit signal and durable processing-work evidence for the six frozen positions, without fetching large explanation payloads. Execute after DBQ-CODEX-I1-001 confirms these columns.  
SQL:
```sql
SELECT
    p.id AS paper_position_id,
    'ENTRY_SIGNAL' AS relation_type,
    s.id AS signal_id,
    s.symbol,
    s.interval_code,
    s.candle_open_time,
    s.decision,
    s.original_decision,
    s.final_entry_allowed,
    s.data_quality_valid,
    s.total_score,
    s.confidence_score,
    s.latest_price,
    s.stop_loss,
    s.take_profit,
    s.risk_reward_ratio,
    s.selected_strategy,
    s.strategy_version,
    s.signal_mode,
    s.generated_at,
    s.created_at
FROM paper_position p
JOIN trade_signal s ON s.id = p.signal_id
WHERE p.id IN (172, 162, 158, 143, 137, 131)

UNION ALL

SELECT
    p.id AS paper_position_id,
    'EXIT_SIGNAL' AS relation_type,
    s.id AS signal_id,
    s.symbol,
    s.interval_code,
    s.candle_open_time,
    s.decision,
    s.original_decision,
    s.final_entry_allowed,
    s.data_quality_valid,
    s.total_score,
    s.confidence_score,
    s.latest_price,
    s.stop_loss,
    s.take_profit,
    s.risk_reward_ratio,
    s.selected_strategy,
    s.strategy_version,
    s.signal_mode,
    s.generated_at,
    s.created_at
FROM paper_position p
JOIN trade_signal s ON s.id = p.exit_signal_id
WHERE p.id IN (172, 162, 158, 143, 137, 131)
  AND p.exit_signal_id IS NOT NULL
ORDER BY paper_position_id, relation_type;

SELECT
    p.id AS paper_position_id,
    w.signal_id,
    w.symbol,
    w.interval_code,
    w.candle_open_time,
    w.origin,
    w.status,
    w.attempts,
    w.failure_stage,
    w.error_message,
    w.paper_position_id,
    w.created_at,
    w.updated_at,
    w.completed_at
FROM paper_position p
LEFT JOIN signal_processing_work w ON w.signal_id = p.signal_id
WHERE p.id IN (172, 162, 158, 143, 137, 131)
ORDER BY FIELD(p.id, 172, 162, 158, 143, 137, 131);
```
### END_DB_REQUEST
