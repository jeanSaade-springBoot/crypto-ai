## FINDINGS

### I6-F01: The 0.50% stop floor with an unscaled target sets reward/risk to 6 × ATR% (ROOT CAUSE, configuration/design; PROJECT EVIDENCE + arithmetic)

**Code:**
- `AtrRiskService.java:34-45` sets `stopDistance = max(2·ATR, 0.50%·price)` (capped at 8%) and `rewardDistance = 3·ATR`, with no floor.
- `application.yml:137-143` sets `stop-loss-multiplier 2.0`, `take-profit-multiplier 3.0` and `minimum-stop-percent 0.50`.

**Effect:** whenever ATR% is below 0.25%, the stop is held at 0.50% while the target shrinks with ATR. Reward/risk then equals 3·ATR% / 0.5 = **6 × ATR%**, and it falls below 1 once ATR% is under 0.1667%.

| ID | ATR% (I5-003) | 6 × ATR% | Stop below entry | Reward/risk at fill (I5-F01) |
|---|---|---|---|---|
| 137 | 0.1073 | **0.644** | 0.50% | 0.644 ✓ |
| 158 | 0.0545 | 0.327 | 0.49% | 0.346 (fill price ≠ signal price) ✓ |
| 162 | 0.0730 | **0.438** | 0.50% | 0.438 ✓ |
| 172 | 0.1240 | **0.744** | 0.50% | 0.744 ✓ |
| 182 | 0.0803 | **0.482** | 0.50% | 0.482 ✓ |
| 143 | 0.2703 | 2 ATR = 0.54% > floor | 0.54% | 1.50 at signal ✓ |

Stop distances were computed from the I1-005 stops and the I1-004 fills.

**No gate uses it:**
- `getRiskRewardRatio()` is read only by the dashboard and inspector (`DashboardApiController:1203,1312,1373`, `TradeInspectorService:1099`).
- The only reward/risk floor in execution is `BREAKOUT_RETRACEMENT_MIN_RR = 1.15` (`EIS:212,1539`), on a route none of the six trades used.
- Entry Quality applies a flat, non-blocking −30 (I5-F02).

This explains *why* I4-F07 and I5-F02 found reward/risk below 1. It is configured arithmetic, not a code defect: the floor protects against stop-hunting noise but silently inverts the payoff.

**Classification:** configuration and design root cause, shared by 137, 158, 162, 172 and 182.

### I6-F03: Defect B was not decisive for trade 143 (closes U5-05; PROJECT EVIDENCE: code + I1-003)

**The 1m signal qualified on its own:**
- #159408 was WATCH with score 73 and confidence 78 (I1-003).
- `isSupportiveCurrentSignal` accepts a WATCH with score ≥ 60 and confidence ≥ 60 (`EIS:73-74, 2214-2219`).
- So `setupTimeframeAtrAuthoritySignal` passes **without** the `healthyNeutralTiming` evidence test (`EIS:1479-1483`). The evidence score of 8 (inflated by pre-exit signals) was never consulted.

**A boundary would not have removed the 5m setup either:**
- FIX-122 `eligible()` filters only evidence, deferred-origin and previous-health inputs (`EIS:1604, 1697, 1802, 2258, 2333`).
- The 5m setup is chosen by `latestAtOrBefore` (`EIS:1485, 2455`), which has no lineage filter.
- So even with a boundary at 22:39:41, 5m #159285 (22:35) would still have been selected.

**Conclusion:** trade 143's decisive defect is **Defect A**, the outdated or reused 5m signal (I3-F02/F03). Defect B is a confirmed intent mismatch (FIX-020 versus stop-loss-only boundaries) that had no effect here.

### I6-F04: The wall-clock age gap only ever runs one way (PARITY DEFECT candidate; PROJECT EVIDENCE: I5-006 + AGENT INFERENCE)

**Mechanism:**
- Replay age is always a whole number of minutes, N (candle-close timestamps).
- Production age is N + δ, where δ = lag at the current signal − lag at the opportunity start.
- `toMinutes()` rounds down, so Production reads N − 1 whenever δ < 0. Penalties apply at N ≥ 21, 41 or 61.
- So Production can be **more lenient, never stricter**, than Replay.

**Population evidence (I5-006, 8 executions near a boundary):**

|---|---|---|---|---|---|---|
| 14674 ENA | 1259.91 | 21 | 20 | 21 | 78 → 73 | +0.350 |
| 24105 AERO | 3656.78 | 61 | 60 | 61 | 60 → 55 | +0.363 |
| **35305 TAO** | 1259.96 | 21 | 20 | 21 | **50 → 45, blocked** | **−0.126 (paper 127, STOPPED)** |
| **37952 DOGE** | 1259.98 | 21 | 20 | 21 | **50 → 45, blocked** | **−0.052 (frozen trade 162)** |
| 14490, 15734, 30238, 38377 | — | — | same | same | no change | — |

**Not yet proven:** that Replay builds the opportunity starting at the same candle. DBQ-CLAUDE-I5-004 came back as an **empty file** (not even a header), so I cannot tell zero rows from a failed run. I6-003 checks this.
