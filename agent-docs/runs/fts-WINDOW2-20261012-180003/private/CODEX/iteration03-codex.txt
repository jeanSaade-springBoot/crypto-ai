The database-timing log records SQL templates and transaction IDs but not bind values, so it cannot link its timings to a position without first resolving symbol, signal, and wallet-position IDs.

- **PROJECT EVIDENCE:** Direct price protection is transactional. `LivePositionProtectionService.onPrice` locks the managed position, validates observation age/order, applies protection, then marks the exact price event `APPLIED` in the same transaction. The post-commit `PRICE_OUTCOME_COMMITTED` log proves committed callback completion, not necessarily a position exit.

### DB_REQUEST

QueryId: DBQ-CODEX-I3-002  
Purpose: Produce a non-cartesian durable timeline of entry, processing, wallet execution, management, audit, and close events. Wallet trades are included only when their `signal_id` equals the position’s entry or exit signal. All timestamps returned are UTC.  
SQL:
```sql
WITH frozen AS (
    SELECT id, symbol, signal_id, exit_signal_id, opened_at, closed_at
    FROM crypto_ai.paper_position
    WHERE id IN (182, 172, 162, 158, 143, 137)
)
SELECT
    f.id AS paper_position_id,
    'PAPER_POSITION_OPENED' AS event_type,
    f.opened_at AS event_at,
    NULL AS source_record_id,
    f.signal_id AS related_signal_id,
    f.symbol
FROM frozen f

UNION ALL

SELECT
    f.id,
    'ENTRY_SIGNAL_GENERATED',
    ts.generated_at,
    ts.id,
    ts.id,
    f.symbol
FROM frozen f
JOIN crypto_ai.trade_signal ts ON ts.id = f.signal_id

UNION ALL

SELECT
    f.id,
    CONCAT('PROCESSING_', spw.status),
    COALESCE(spw.completed_at, spw.updated_at),
    spw.signal_id,
    spw.signal_id,
    f.symbol
FROM frozen f
JOIN crypto_ai.signal_processing_work spw ON spw.signal_id = f.signal_id

UNION ALL

SELECT
    f.id,
    'EXIT_SIGNAL_GENERATED',
    ts.generated_at,
    ts.id,
    ts.id,
    f.symbol
FROM frozen f
JOIN crypto_ai.trade_signal ts ON ts.id = f.exit_signal_id

UNION ALL

SELECT
    f.id,
    CONCAT('WALLET_TRADE_', wt.side, '_', COALESCE(wt.execution_reason, 'NONE')),
    wt.executed_at,
    wt.id,
    wt.signal_id,
    f.symbol
FROM frozen f
JOIN crypto_ai.wallet_trade wt
    ON wt.signal_id IN (f.signal_id, f.exit_signal_id)

UNION ALL

SELECT
    f.id,
    CONCAT('MANAGEMENT_', pme.event_type),
    pme.occurred_at,
    pme.id,
    NULL,
    f.symbol
FROM frozen f
JOIN crypto_ai.production_exit_audit pea
    ON pea.paper_position_id = f.id
JOIN crypto_ai.position_management_event pme
    ON pme.wallet_position_id = pea.wallet_position_id

UNION ALL

SELECT
    f.id,
    CONCAT('EXIT_AUDIT_', pea.close_trigger),
    pea.audited_at,
    pea.id,
    pea.source_signal_id,
    f.symbol
FROM frozen f
JOIN crypto_ai.production_exit_audit pea
    ON pea.paper_position_id = f.id

UNION ALL

SELECT
    f.id,
    'PAPER_POSITION_CLOSED',
    f.closed_at,
    NULL,
    f.exit_signal_id,
    f.symbol
FROM frozen f
ORDER BY paper_position_id, event_at, source_record_id;
```

### DB_REQUEST

QueryId: DBQ-CODEX-I3-003  
Purpose: Retrieve bounded symbol-level protection evidence for the final three UTC minutes before each selected close. These records are not position-linked; they must be reconciled with the durable audit and management evidence before attribution.  
SQL:
```sql
WITH frozen AS (
    SELECT id AS paper_position_id, symbol, entry_price, stop_loss,
           take_profit, exit_price, opened_at, closed_at
    FROM crypto_ai.paper_position
    WHERE id IN (182, 172, 162, 158, 143, 137)
),
ranked_events AS (
    SELECT
        f.paper_position_id,
        f.symbol,
        f.entry_price,
        f.stop_loss,
        f.take_profit,
        f.exit_price,
        f.closed_at,
        mpe.id AS market_price_event_id,
        mpe.observed_at,
        mpe.price,
        mpe.source,
        mpe.source_received_at,
        mpe.delivery_status,
        mpe.ordering_slot,
        mpe.outcome_reason,
        ROW_NUMBER() OVER (
            PARTITION BY f.paper_position_id
            ORDER BY mpe.observed_at DESC, mpe.id DESC
        ) AS recency_rank
    FROM frozen f
    JOIN crypto_ai.market_price_event mpe
      ON mpe.symbol = f.symbol
     AND mpe.observed_at >= f.closed_at - INTERVAL 180 SECOND
     AND mpe.observed_at <= f.closed_at
)
SELECT
    paper_position_id,
    symbol,
    entry_price,
    stop_loss,
    take_profit,
    exit_price,
    closed_at,
    market_price_event_id,
    observed_at,
    price,
    source,
    source_received_at,
    delivery_status,
    ordering_slot,
    outcome_reason
FROM ranked_events
WHERE recency_rank <= 500
ORDER BY paper_position_id, observed_at, market_price_event_id;
```
