## EVIDENCE: entry-quality ledger (PROJECT EVIDENCE)

Scoring rules (EIS `:976-1022`):
- Start at 100.
- **R/R < 1 costs −30**, whether R/R is 0.01 or 0.99.
- Expansion from the 30-minute reference low: −10 / −22 / −35 / −50.
- ATR extension: −10 / −20 / −30.
- Opportunity age: −5 / −10 / −15.
- Rejection zone: −12, but **floored at 50** if the score was ≥ 50 before the penalty.
- HIGH_VOLATILITY −10, STOP_EXPOSED −15, BREAKOUT bonus +5.

What the score does:
- The only block is score < 50 (`CHASE_ENTRY_CUTOFF`).
- Otherwise it caps size: ≥ 85 → 50%, ≥ 70 → 40%, else 25%.
- Final size = cap × the signal's ATR-recommended % (PTS `:328-333`).

| Trade | Route / HTF authority | EQ used for the decision | EQ persisted (at fill price) | R/R | Target % / Stop % | ATR rec. % | Final size |
|---|---|---|---|---|---|---|---|
| 137 | IMMEDIATE / FIX-11G | 58 ACCEPTABLE | 58 | 0.64 | +0.322 / −0.500 | 100 | 25% |
| 143 | SETUP_TIMEFRAME_ATR (EQ uses 5m ATR) | **60** | **70** | 1.50 | +0.786 / −0.565 | **0 → treated as 100** | 25% |
| 158 | WAKEUP / BALANCED_STRONG 75 | not logged (≤ 69, since the cap applied) | **50** | 0.33 | +0.171 / −0.493 | 100 | 25% |
| 162 | ACCUMULATED / BALANCED_EARLY | **50 LATE_ENTRY** | **50** | 0.44 | +0.219 / −0.500 | 60 | 15% |
| 172 | IMMEDIATE / BALANCED_STRONG 75 | 60 ACCEPTABLE | 60 | 0.74 | +0.372 / −0.500 | 100 | 25% |
| 182 | IMMEDIATE / FIX-11G | **50 LATE_ENTRY** | **50** | 0.48 | +0.241 / −0.500 | 60 | 15% |

**Resolved:** the 15% size on 162 and 182 is round(60% ATR × 25% cap) (PTS `:332-333`). It is not a separate cap.

## FINDINGS

### F-30: Entry Quality cannot reject an R/R < 1 entry; it only sizes it (PROJECT EVIDENCE; design gap)

- The R/R penalty is flat: −30 for anything below 1, with no fee term (`EIS:991`, `:1811-1817`).
- Starting from 70, an R/R < 1 entry still passes the 50 cutoff as long as all other penalties total ≤ 20.
- 5 of the 6 entries had R/R 0.33–0.74, so each started at 70 at most.
- **All six scored 50–60 on the score that governed the decision. Three (158, 162, 182) sat at exactly 50, the lowest passing value.**
- **AGENT INFERENCE:** the rejection-zone floor (`:1000-1002`) turns 50 into a sink value. A trade at 50 may have absorbed penalties well beyond the cutoff. Which components produced each score is pending I5-001 to I5-003.

### F-31: net of fees, the planned trades had almost no edge (PROJECT EVIDENCE + EXTERNAL RESEARCH)

- **External research:** the standard Binance spot rate (VIP 0) is 0.1% per side, or 0.075% if paid in BNB. That makes a round trip 0.15–0.20%. Sources are mostly third-party; one unverified report says maker fees are now 0.
- At 0.2% round trip, net R/R would be:

| Trade | Net R/R | Win rate needed to break even |
|---|---|---|
| 137 | 0.17 | — |
| 143 | 0.77 | — |
| 158 | **negative** (the target is below the fee) | — |
| 162 | 0.03 | about 97% |
| 172 | 0.25 (0.46 with tick rounding) | — |
| 182 | 0.06 | about 94% |

- `wallet_trade.fee_usdt = 0`, and neither Entry Quality nor R/R models fees.
- This makes F-10 stronger: these are **structurally negative-expectancy entry plans**, separate from whether the signal was right.

### F-32: FIX-11G admits LATE_ENTRY prices that the stronger BALANCED_EARLY authority blocks (PROJECT EVIDENCE; candidate design gap, trade 182)

- FIX-041 blocks a direct BUY only when the validation code is `BALANCED_EARLY` **and** Entry Quality is LATE_ENTRY (`EIS:672-673`). BALANCED_EARLY means 5m WATCH + 1h WATCH.
- FIX-11G (`BALANCED_NEUTRAL_5M_WATCH_1H`) is a **weaker** authority (5m NEUTRAL), yet it only requires EQ ≥ 50 (`TEVS:49, :266`). FIX-041 does not cover it.
- 182 went through this path at **exactly 50 / LATE_ENTRY**. Its 5m context 176655 had originally been STRONG_SELL (F-26).
- **AGENT INFERENCE:** had 182 come through BALANCED_EARLY, it would have been held as `BALANCED_EARLY_LATE_ENTRY_BLOCKED`. Ranking the authorities like this is inconsistent.

### F-33: on the accumulated-evidence route, one BUY in 30 minutes lets a LATE_ENTRY through (PROJECT EVIDENCE; candidate design gap, trade 162)

- FIX-119 defers an `ACCUMULATED_EVIDENCE` LATE_ENTRY only when buyCount = 0 and the 5m is not bullish (`EIS:1271-1280`).
- 162 had "1 BUY, 9 WATCH", 5m WATCH and HTF authority BALANCED_EARLY. One BUY observation was enough to skip the deferral.
- Its signal showed the price at or above the upper Bollinger band, 2.82 ATR above SMA20, and RSI 68 (I1-007).
- The same BALANCED_EARLY + LATE_ENTRY combination is blocked on the direct path (FIX-041).
- The age, price and freshness of that single BUY are pending (I5-002).

### F-34: on trade 143, the score that set the size differs from the score persisted (PROJECT EVIDENCE + AGENT INFERENCE)

- The decision used EQ **60**, computed with the 5m ATR (`EIS:634`).
- The persisted `entry_quality_score` is **70**, re-scored at the fill price with the **1m** ATR (`PTS:377-385`, `EIS:857`).
- The difference is one 10-point tier. That means the **5m ATR produced the larger ATR extension**. This contradicts the code comment's premise that a "tiny 1m ATR" inflates chase scores.
- **AGENT INFERENCE:** the 22:39 1m candle had RVOL 21.9×, which inflated the 1m ATR14. Pending `atr_at_signal` (I5-001).
- **Audit consequence:** the persisted score is not always the score that governed sizing.

### F-35: an ATR plan of "0% recommended" is treated as 100% (PROJECT EVIDENCE; latent gap, no P&L impact here)

- The code does `atrPercent <= 0 ? 100 : …` (`PTS:328-330`). An explicit 0% from `WAIT_FOR_RETRACEMENT` is indistinguishable from "missing".
- For 143 the 5m plan allowed 100%, so the size would have been the same either way.
