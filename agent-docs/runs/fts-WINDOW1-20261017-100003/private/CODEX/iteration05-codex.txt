### DB_REQUEST

QueryId: DBQ-CODEX-I5-002  
Purpose: After confirming the physical schema from I5-001, retrieve the entry-signal and wallet-execution evidence required to measure decision-to-fill drift and assess entry quality using only information available by each entry time.  
SQL:
```sql
SELECT pp.id AS paper_position_id,
       pp.symbol AS position_symbol,
       pp.signal_id AS entry_signal_id,
       pp.opened_at AS position_opened_at_utc,
       pp.entry_price AS position_entry_price,
       pp.stop_loss AS position_stop_loss,
       pp.take_profit AS position_take_profit,
       pp.entry_reason,
       ts.*,
       wt.*
FROM crypto_ai.paper_position pp
LEFT JOIN crypto_ai.trade_signal ts
       ON ts.id = pp.signal_id
LEFT JOIN crypto_ai.wallet_trade wt
       ON wt.signal_id = pp.signal_id
      AND wt.side = 'BUY'
      AND wt.status = 'EXECUTED'
WHERE pp.id IN (182, 172, 162, 158, 143, 137)
ORDER BY FIELD(pp.id, 182, 172, 162, 158, 143, 137),
         wt.executed_at ASC;
```
### END_DB_REQUEST
