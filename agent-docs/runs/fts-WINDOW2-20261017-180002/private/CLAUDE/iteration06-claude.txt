### F6-3 [PE code + DB I5-002/I5-003]: all six EQ scores reproduce exactly from code (resolves U5-1 and U5-2)

**How the score is built (`ExecutionIntelligenceService.java`):**
- Reference price = the rolling 30-minute low, replaced by the opportunity anchor or best price if that is lower (`:900-926`).
- Penalties:
  - Expansion above the reference: −10 for over 1.5% (`:978-981`).
  - ATR extension: −10 above 2.5 ATR, −20 above 4, −30 above 6 (`:983-985`).
  - Opportunity age: −10 above 40 minutes (`:987-989`).
  - R:R below 1: −30 (`:991`).
  - Rejection zone: −12, but it cannot pull a score that was at or above 50 below 50 (`:995-1003`).

## DB REQUESTS

Time literals are KSA (the session is +03:00). All requests are read-only and bounded.

### DB_REQUEST
QueryId: DBQ-CLAUDE-I6-001
Purpose: Split the system-wide gross loss by status, by stop floored or not, and by ATR% group. This sizes the STOPPED class the charter excluded (F6-1, F6-7, U6-2).
SQL:
SELECT p.status, CASE WHEN ROUND((s.latest_price - s.stop_loss)/s.latest_price*100,2) <= 0.51 THEN 'floored' ELSE 'atr' END AS stop_kind, CASE WHEN s.atr_percent < 0.10 THEN 'a_lt0.10' WHEN s.atr_percent < 0.25 THEN 'b_0.10-0.25' WHEN s.atr_percent < 0.50 THEN 'c_0.25-0.50' ELSE 'd_ge0.50' END AS atr_bucket, COUNT(*) AS n, SUM(p.realized_pnl < 0) AS losers, ROUND(SUM(p.realized_pnl),4) AS pnl_gross, ROUND(SUM(p.realized_pnl - 0.001*p.quantity*(p.entry_price + p.exit_price)),4) AS pnl_after_fee, ROUND(AVG((p.exit_price - p.entry_price)/p.entry_price*100),3) AS avg_move_pct FROM crypto_ai.paper_position p JOIN crypto_ai.trade_signal s ON s.id = p.signal_id WHERE p.closed_at IS NOT NULL GROUP BY p.status, stop_kind, atr_bucket ORDER BY p.status, stop_kind, atr_bucket LIMIT 40;
### END_DB_REQUEST

### DB_REQUEST
QueryId: DBQ-CLAUDE-I6-002
Purpose: Test whether entries that follow a run of 1m SELL signals lose system-wide (F6-5, U6-4). The count uses 1m LIVE SELL/STRONG_SELL signals in the 15 minutes before the entry signal.
SQL:
SELECT CASE WHEN x.sells_15m >= 10 THEN 'a_ge10' WHEN x.sells_15m >= 5 THEN 'b_5-9' WHEN x.sells_15m >= 1 THEN 'c_1-4' ELSE 'd_0' END AS sell_run, COUNT(*) AS n, SUM(x.realized_pnl < 0) AS losers, SUM(x.status='STOPPED') AS stopped, ROUND(SUM(x.realized_pnl),4) AS pnl_gross FROM (SELECT p.id, p.status, p.realized_pnl, (SELECT COUNT(*) FROM crypto_ai.trade_signal q WHERE q.symbol = s.symbol AND q.interval_code='1m' AND q.signal_mode='LIVE' AND q.decision IN ('SELL','STRONG_SELL') AND q.generated_at >= DATE_SUB(s.generated_at, INTERVAL 15 MINUTE) AND q.generated_at < s.generated_at) AS sells_15m FROM crypto_ai.paper_position p JOIN crypto_ai.trade_signal s ON s.id = p.signal_id WHERE p.closed_at IS NOT NULL) x GROUP BY sell_run ORDER BY sell_run;
### END_DB_REQUEST

### DB_REQUEST
QueryId: DBQ-CLAUDE-I6-003
Purpose: Find the TP-extension columns, then count positions whose highest price passed the original signal TP but which closed at a loss (U6-5, 143 mechanism).
SQL:
SELECT TABLE_NAME, COLUMN_NAME, DATA_TYPE FROM information_schema.COLUMNS WHERE TABLE_SCHEMA='crypto_ai' AND TABLE_NAME IN ('paper_position','wallet_managed_position','production_exit_audit') AND (COLUMN_NAME LIKE '%take_profit%' OR COLUMN_NAME LIKE '%extension%' OR COLUMN_NAME LIKE '%highest%' OR COLUMN_NAME LIKE '%floor%' OR COLUMN_NAME LIKE '%reason%') ORDER BY TABLE_NAME, COLUMN_NAME;
SELECT p.status, COUNT(*) AS n, SUM(p.realized_pnl < 0) AS losers, ROUND(SUM(p.realized_pnl),4) AS pnl_gross FROM crypto_ai.paper_position p JOIN crypto_ai.trade_signal s ON s.id = p.signal_id WHERE p.closed_at IS NOT NULL AND p.highest_price >= s.take_profit GROUP BY p.status;
### END_DB_REQUEST
