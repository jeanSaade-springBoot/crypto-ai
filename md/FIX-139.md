# FIX-139 — Collector-backed candle health

## Incident and scope
The 2026-09-29 21:28 UTC health response has one overall critical alert: candle-staleness query timeout. All 63 signal freshness rows are OK. Daily candle counts incorrectly use the local trader candle table.

## Changes
- Candle counts use SharedMarketSource.reader(): collector in LIVE, local in OFF/OBSERVE, preserving source routing semantics.
- Serial count queries use symbol/interval/closed equality and a bounded daily open-time range. Counts explicitly cover enabled symbols and the existing three monitored intervals only.
- Freshness uses symbol/interval/closed equality, four-hour close/open bounds, ORDER BY close_time DESC LIMIT 1. Open cutoff preserved; close bound also limits index traversal when no qualifying candle exists.
- Existing collector indexes (symbol,interval_code,closed,open_time) and (symbol,interval_code,closed,close_time) support these shapes. No schema change or index creation.
- Existing 45-second default snapshot cache and single-flight synchronization retained. For 21 enabled symbols, 63 small freshness reads and 63 bounded count reads occur serially per cache miss. These replace two broad scans. No parallel fan-out, new executor, polling, pool expansion or timeout increase.
- Empty enabled-symbol set fails the diagnostic explicitly instead of reporting healthy empty coverage.
- Missing-history wording now accurately says no data in the last four hours.
- Query failure remains visible as CRITICAL; this patch does not hide diagnostics.

## Boundaries and limits
No scoring, worker, dispatch, ownership, signal-generation, execution or wallet change. BNB event 1017877 is NOT requeued or changed. Shutdown lifecycle repair is separate.
Daily baseline comparison and timeframe expansion are deferred to keep this incident patch narrow; partial-day/full-day baseline warnings remain unchanged.
Serial point reads add round trips; production latency/load must be measured, not assumed. Counts still scan qualifying day rows. No guarantee of zero performance impact.

## Validation
Added SystemHealthCollectorReadTest using separate H2 local/collector databases: collector routing, open-candle exclusion, enabled-symbol restriction, stale/missing detection and local-source fallback. Existing cache tests retained.
Authoring runtime only has Java 17 and no Maven. javac parser checks syntax only: no dependency/type checking, Java 21 build, JUnit execution or real MySQL EXPLAIN/runtime validation performed.
