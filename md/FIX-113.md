# FIX-113 — Catching Market and Trade Inspector read-only UI performance

## Golden rule
Replay = Production. FIX-113 is read-only presentation/retrieval work and must not alter Production or Replay trading behavior.

## Catching Market
- Server-side aggregation by persisted symbol, direction and catcher window.
- Database-derived count, average progress, start time and end time.
- Fixed 20-row server pagination ordered by latest activity.
- History filters: 1 hour, 4 hours, 24 hours.
- View Chart uses a lightweight bounded candle query and highlights the persisted aggregate start event's **start time only**.
- No signal/execution/blame reconstruction is performed by the new fast chart endpoint.

## Trade Inspector
- Filter-free completed-trade browsing.
- Page 1 always requests the latest 10 records.
- Previous/Next walks the server-paged historical ledger.
- Existing trade View Chart and View Path behavior is retained.

## Explicitly unchanged
- Price catcher detection rules and thresholds.
- Signal generation and FinalDecision.
- ExecutionIntelligence and wallet execution.
- Replay business logic and parity authority.
