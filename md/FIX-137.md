# FIX-137 — Worker diagnostics

Logging-only patch based on the uploaded src(20260928-210203).zip.
Merge the included src files into the Trader project.

## Default INFO/WARN/ERROR
- ANALYSIS_CLAIMED: durable claim returned successfully; not execution completion.
- ANALYSIS_TASK_START: event, symbol/timeframe lane and executor queue wait.
- WORKER_START / WORKER_END: exact candle, source event, outcome and elapsed time.
- EXISTING_SIGNAL_REVIEW: existing signal lacks matching completed shared work; does not prove work is absent.
- ANALYSIS_ABORTED: cutover admission changed before worker invocation.
- ANALYSIS_TASK_END: outcomeCommitted=true only after the outcome update matched and its transaction returned successfully.
- OUTCOME_COMMIT_UNCONFIRMED / OUTCOME_NOT_PERSISTED: persistence failure or ownership/status mismatch.
- DISPATCH_START / DISPATCH_CANDIDATES / DISPATCH_END: heartbeat every 30 seconds while dispatch runs; slow completed cycles also emit END.
A START without END indicates a cycle still in progress or an interrupted process, not proof of a specific SQL failure.
REVIEW_REQUIRED and other non-success outcomes are not healthy completions.

## Detailed DEBUG
Enable only these two loggers temporarily via launch arguments:
--logging.level.com.crypto.indicator.event.CandleClosedAnalysisWorker=DEBUG
--logging.level.com.crypto.shared.SharedMarketConsumer=DEBUG

WORKER_STAGE identifies coordination wait, data quality, indicators, existing-signal check,
historical signal creation, live signal/registration, and signal processing.
Elapsed stage values are cumulative from worker start, not individual SQL execution times.
DISCOVERY_BATCH, DELIVERY_START, DELIVERY_STAGE_RETURNED and ANALYSIS_WAIT show consumer progress.
DELIVERY_STAGE_RETURNED can be a guarded no-op; it does not certify a phase advance.
Candidates excluded by the SQL blocker predicate never reach ANALYSIS_WAIT.
Existing legacy log markers remain; prefer outcomeCommitted when assessing persistence.
DEBUG delivery logs can be high volume. Return those loggers to INFO after diagnosis.

## Scope and validation
No new queries, status repairs, automatic retries, signal rules or execution ordering changes.
This patch does not fix or clear the existing REVIEW_REQUIRED backlog.
Source diff reviewed. Full Maven compilation/tests were not run: available Java is 17,
the project requires Java 21, and Maven is absent. Run the normal Jenkins build/tests.
No credentials, candle payloads or SQL parameters are added to diagnostic messages.
